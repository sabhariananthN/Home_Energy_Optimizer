# Home Energy Consumption Optimizer

## Project Description

Home Energy Consumption Optimizer is an AI-based mini project
that analyzes household appliance energy consumption and provides
energy-saving recommendations.

## Technologies Used

- Python
- Streamlit
- Pandas
- Rule-Based AI

## Features

- Add household appliances
- Enter power rating
- Enter daily usage hours
- Calculate daily energy consumption
- Estimate monthly consumption
- Display energy consumption chart
- Generate AI-based recommendations

## Formula

Energy Consumption = Power × Usage Hours / 1000

## Objective

To help users understand their household energy consumption
and reduce unnecessary electricity usage.
